LRP - Laboratuvar Kaynak Planlama Sistemi
Bu proje, okul laboratuvarlarındaki bilgisayarların takibi ve öğrenci zimmet işlemlerini yönetmek için geliştirilmiştir.

🚀 Nasıl Çalıştırılır?
Proje klasöründe terminali açın.

dotnet run komutunu çalıştırın.

Tarayıcıdan http://localhost:7137/login.html adresine gidin.

🔑 Giriş Bilgileri
Admin: admin / 1234

Öğrenci: (Admin panelinden zimmetlenen öğrenci numarası / şifre de aynıdır)

🛠️ Kullanılan Teknolojiler
.NET 8.0 Minimal APIs, Entity Framework Core (SQLite), Vanilla JavaScript, Bootstrap 5.
